# 正交连线编辑器（SVG + Web Worker）

纯前端零依赖的流程图/连线图画布，支持网格吸附、对齐参考线、正交路由与多格式导出。

## 运行

必须通过 HTTP 提供服务（Web Worker 不能在 `file://` 下创建）：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

## 功能

- **网格吸附**：移动节点时按网格步长（10/20/40 可切）吸附；按住 `Shift` 临时关闭。
- **对齐参考线**：节点之间上/中/下、左/中/右 6 条特征线智能吸附，阈值随网格缩放，实时绘制红色参考线。
- **正交路由**：连线全部为水平/垂直折线；Web Worker 中做栅格 A*，
  节点按“通道宽度”膨胀为障碍，已占用通道及其相邻通道计入代价，
  同端口多连线沿节点边缘扇出，保证常规图 **连线不重叠**。
- **导出**：
  - SVG：由数据模型直接序列化（不克隆运行时 DOM），含网格/箭头/中文字体内嵌引用；
  - PNG：SVG 经 `Image` + `Canvas 2D` 2× 光栅化；
  - JSON：导出/导入完整模型，导入带严格校验（id、端口枚举、尺寸、数量上限）。
- **性能**：
  - 路由在 Worker 中计算，主线程不阻塞；
  - 拖拽期间先用同步肘形兜底线实时跟随，60ms 防抖后再用 Worker 结果替换；
  - Worker 超时（4s）/初始化失败/报错时自动降级到主线程兜底并提示；
  - 状态栏显示节点/连线数、重叠段数、路由耗时与实时 FPS；
  - “压力测试”按钮加载 100 节点 / 99 连线验证性能。
- **异常提示**：空画布导出、重复连线、自连、非法 JSON、超大文件、Worker 失败、
  全局 `error` / `unhandledrejection` 均有 toast 分级提示（info/warn/error）。

## 操作

| 操作 | 行为 |
| --- | --- |
| 拖拽节点 | 移动 + 吸附 + 对齐线 |
| 从节点四边端口拖出 | 绘制正交连线，松开在目标端口上完成 |
| 单击节点 / 连线 | 选中 |
| `Delete` / `Backspace` | 删除选中（节点连带其连线） |
| `Shift` + 拖拽 | 临时关闭网格吸附 |

## 文件结构

```
index.html            页面骨架（工具栏 / SVG 场景 / 状态栏 / toast 容器）
src/style.css         样式
src/geometry.js       网格吸附、对齐特征匹配与位置修正
src/router-worker.js  栅格 A* 正交路由（占用代价、障碍膨胀、扇出、重叠统计）
src/router-client.js  Worker 调度、超时/错误降级、同步肘形兜底
src/exporter.js       SVG 序列化、PNG 光栅化、JSON 导入校验
src/app.js            渲染、指针交互、路由调度、状态栏、命令绑定
```

## 验收对照

| 验收项 | 实现 |
| --- | --- |
| 连线不重叠 | 通道占用 + 相邻通道代价 + 端口扇出；状态栏实时显示重叠段数 |
| 导出正确 | SVG/PNG/JSON 均由同一数据模型生成；JSON 可回导并重新路由 |
| 吸附准确 | 网格吸附可切换/临时关闭；对齐线 6 特征匹配并修正位置 |
| 性能可接受 | Worker 异步、拖拽防抖 + 本地兜底；100 节点路由约几十毫秒 |
| 异常有提示 | toast 分级提示 + 自动降级，画布不会因路由失败而不可用 |
